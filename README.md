# Emotion Recognition

Учебно-исследовательский проект по распознаванию эмоционального состояния человека по аудио- и видеоданным. Репозиторий объединяет классические методы извлечения признаков, визуализацию данных и эксперименты с нейронными сетями на PyTorch.

Проект выполнен в рамках курса «Нейронные сети» Томского политехнического университета.

## Направления работы

- анализ эмоций по голосовым признакам;
- анализ эмоций по кадрам лица;
- обучение аудиомодели `STPNet`;
- обучение видеомодели на базе ResNet;
- подготовка аудио- и видеоданных;
- оценка качества по кадрам и клипам;
- визуализация признаков и проекций t-SNE.

## Структура

```text
audio_feature_classification/  классические аудиопризнаки и OpenSMILE
video_feature_classification/  классические визуальные признаки
data_visualization/            графики и t-SNE
pytorch/AEmotionNet/           аудиомодель STPNet
pytorch/VEmotionNet/           видеомодель на базе ResNet
pytorch/common/                загрузка, предобработка, обучение и метрики
методичка.doc                  материалы курса
```

## Модели

### AEmotionNet

Аудиомодель принимает mel-спектрограммы, подготовленные с помощью `librosa`, и использует `STPNet` для предсказания характеристик эмоционального состояния.

### VEmotionNet

Видеомодель обрабатывает последовательности кадров лица и использует CNN на базе ResNet. Реализованы нормализация, аугментация изображений, пакетная загрузка и обучение на GPU.

## Данные

В примерах используются структуры датасетов OMG-Emotion Challenge, AFEW-VA и RAVDESS/Ryerson. Датасеты и предобученные веса в репозиторий не включены: их необходимо получить самостоятельно с соблюдением соответствующих лицензий.

## Подготовка окружения

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\activate
pip install torch torchvision numpy opencv-python librosa pyyaml scikit-learn matplotlib tqdm tensorboardX
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install torch torchvision numpy opencv-python librosa pyyaml scikit-learn matplotlib tqdm tensorboardX
```

Для обучения на GPU установите сборку PyTorch, соответствующую версии CUDA.

## Настройка

1. Подготовьте датасет и файловые списки.
2. Замените локальные пути в `pytorch/AEmotionNet/config.yml` или `pytorch/VEmotionNet/config.yml`.
3. Настройте каталоги журналов и снимков модели.
4. При дообучении укажите путь к начальным весам.
5. Проверьте размер батча и номер CUDA-устройства.

Текущие конфигурации содержат локальные пути автора и служат примерами.

> В `config.yml` пути записаны строками, тогда как `main.py` обращается к ним через ключ `--host`. Для запуска этой версии необходимо добавить вложенные ключи окружений либо адаптировать чтение конфигурации.

## Запуск нейросетевых экспериментов

После согласования конфигурации:

```bash
cd pytorch/AEmotionNet
python main.py --config config.yml --host local
```

или:

```bash
cd pytorch/VEmotionNet
python main.py --config config.yml --host local
```

Значение `--host` должно совпадать с ключом окружения в подготовленной конфигурации.

## Классические методы

Настройте пути к датасету и OpenSMILE в `audio_feature_classification/main.py`, затем выполните:

```bash
python audio_feature_classification/main.py
```

Для эксперимента с изображениями:

```bash
python video_feature_classification/main.py
```
